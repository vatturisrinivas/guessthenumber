
# GuessTheNumber 🎯

A full-stack number guessing game built using React and Java Spring Boot.

## Technologies Used

### Frontend
- React
- JavaScript
- CSS
- Vite

### Backend
- Java
- Spring Boot
- REST APIs

## Features

- Random number generation
- Three guessing attempts
- Too high / Too low hints
- Win and lose conditions
- Restart game functionality
- Separate frontend and backend architecture

## Project Structure

GuessTheNumber/
- guessthenumber-backend/
- guessthenumber-frontend/

## Running the Project

### Backend

Run the Spring Boot application from Eclipse.

Backend URL:
http://localhost:8080

### Frontend

Navigate to the frontend directory:

```bash
cd guessthenumber-frontend
npm install
npm run dev
```

Frontend URL:
http://localhost:5173
